「深色模式」最简单的实现是 `filter: invert(1)`，或者把手写死的颜色挨个换成反色。这两种做法出来的东西都很难看。

难看的原因是：**深色下的对比度感知和浅色完全不同**。同一组灰色放到深底上，看着会明显更暗、更脏。

## 三版方案

### 第一版：纯黑底 + 纯白字

对比度拉满了，但看十分钟眼睛会累。原因是纯黑底上的纯白字在液晶屏上会产生明显的光晕（halation），尤其是字号小的时候。

### 第二版：把浅色直接反相

得到的是一堆灰紫色。因为原本的暖色调（纸白 `#F3F2EE`）反相之后变成了冷紫，整页像坏掉的显示器。

### 第三版：重新定一套色，只保证「关系」一致

最后选了深灰蓝 `#16181C` 做底，米白 `#E8E6E1` 做字。关键不是这两个值本身，而是**它们在各自的底色上，与背景的明度差要保持接近**。

## 落地时的两个细节

**一、用 CSS 变量，而不是到处写判断。**

```css
:root {
  --bg: #f3f2ee;
  --ink: #1f0909;
}

[data-theme='dark'] {
  --bg: #16181c;
  --ink: #e8e6e1;
}
```

组件里永远只写 `var(--bg)`。这样加主题不需要改任何组件，改的只是变量的取值。

**二、第一屏不能闪。**

主题是运行时才知道的（存在 localStorage 里），如果等 JS 执行完再切，用户会看到一瞬间的白底。做法是在 `<head>` 里放一段**同步执行的内联脚本**，在渲染之前就把 `data-theme` 写到 `<html>` 上。

这也是为什么主题要写在 `document.documentElement` 而不是某个组件根节点上——它得在 Vue 挂载之前就位。
